# Demo Library

A complete, freely-licensed library folder, for trying kleib3ry without your own
books. Credits and licences below.

**These files are not under the project's MIT licence.** They are other people's
work, and the licences differ from one to the next — the record below is
NonCommercial, the video is CC0. The root [LICENSE](../../LICENSE) says the same
thing from the other side. Reusing kleib3ry? Delete this folder; nothing in the
application depends on it.

## Books

Public domain in the United States; check your own jurisdiction if that matters
to you.
