# Ideas / Features

- EPUB reading. The reader has no text layout engine, so EPUBs are indexed, shelved and handled as objects but cannot be opened. This is the largest single gap left in the app.
- A way to search the library from inside the room — the catalogue is a thousand spines and no index. Add an old-school, very simple, computer to the office where you can search for books, music etc. Like an index in an old library.
- Weather, or at least rain on the windows. The lake and the forest already change between day and night; nothing else does.
- Sound in the room rather than in the browser: the record player and the television both play at one volume from everywhere.
- A second building. The world document can already describe one; there is no reason a library folder could not hold two and a path between them. Create a tiny lake house.
- Make the office bigger; I want more space on the whiteboard.
- The whiteboard is hanging too low.
